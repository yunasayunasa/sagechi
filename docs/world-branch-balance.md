# 白・黒ワールドっち進化バランス

## 調整理由

以前は `careSuccess` が正解のお世話ごとに白側へ加点され、撫でる・休むの穏やか加点も強かったため、要求へ丁寧に応える通常プレイが白へ偏りすぎていた。

## 現在の方針

- 正解した事実を示す `careSuccess` はほぼ中立になるようWeightを0.05へ縮小する。
- 穏やか方向は撫でる、休む、野菜、絵本で形成する。
- 活発方向はボール、ガラガラ、肉、あとでね、ストレス履歴で形成する。
- Active ScoreがCalm Scoreの90%以上なら黒ワールドっちを選ぶ。
- 履歴が完全に空の場合だけは白をFallbackとする。

これにより「おねだりへ応えたか」ではなく「何を選んで応えたか」が白黒へ強く反映される。
