# Phase 8 卵・世代交代・タルトマンっち

## 卵と世代

- 最終進化後、フォアグラウンド120秒かつお世話8回で卵を出現させる。
- 卵があっても現在個体の育成を続けられる。
- 世代交代では現在個体を外し、ワールドっち、Stage 1、初期Status／Historyへ戻す。
- `generation`を1増やし、図鑑、マップ、設定は保持する。
- Background中は成人時間を加算しない。

## レア要求

- `generation >= 1`で通常抽選が食事要求になった時、その5%をタルト要求へ置換する。
- 要求はSave V7へ保存し、Reloadで消えない。
- タルト要求への回答時だけ食事選択へタルトを追加する。
- タルト以外または「あとでね」なら通常完了し、後の食事要求で再抽選する。
- タルトを与えると現在段階を問わずタルトマンっちへ即時進化する。タルトマン自身には再発生しない。

## 図鑑

- 11枠目を未発見の秘密シルエットとして表示する。
- 発見後は名前、説明、ヒント、本番GLBの3D Previewを表示する。
