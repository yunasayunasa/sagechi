# Phase 7 病気・看病

## 方針

- 病気は死亡リスクではなく、育成履歴と個性を作るイベントとして扱う。
- Care回数が3回未満では発生しない。
- 通常時は20秒ごとの判定で1.5%、ストレス60以上・健康70以下・あとでね2回以上のいずれかでは12%で発生する。
- 判定はゲームがフォアグラウンドで進行している間だけ行う。

## 看病フロー

1. 寒そう → あたためる
2. 眠そう → 休ませる
3. おなかが空いた → 野菜を与える
4. 「しっかり休めた」→ 回復

別の食事、「冷やす」「起こす」などのハズレ、または「あとでね」を選ぶと、現在の吹き出しは閉じる。病気と看病段階は維持し、次のおねだり時刻に通常要求より優先して同じ看病要求を再表示する。ハズレでは怒るReactionを再生する。病気中の「あとでね」は進化・卵用のお世話回数として加算しない。

## 表現

- 賢者っちはAnimationと移動速度を低下させ、Emissiveを弱める。
- ワールドっち系は浮遊・移動・発光を弱める。
- ステータスカードへ「看病中」を表示する。

## Save

Save schema V11で `illnessActive`、`illnessStep`、`pendingRequestChoice` を保存する。V1〜V10からMigrationし、既存データを維持する。世代交代時は病気状態を解除する。
