# Phase 7 病気・看病

## 方針

- 病気は死亡リスクではなく、育成履歴と個性を作るイベントとして扱う。
- Care回数が3回未満では発生しない。
- 通常時は20秒ごとの判定で1.5%、ストレス60以上・健康70以下・あとでね2回以上のいずれかでは12%で発生する。
- 判定はゲームがフォアグラウンドで進行している間だけ行う。

## 看病フロー

「寒そう→あたためる」「眠そう→休ませる」「空腹→野菜を与える」から、直前と異なる内容をランダムに選ぶ。3回正しく看病すると回復する。

別の食事、「冷やす」「起こす」などのハズレ、または「あとでね」を選ぶと、現在の吹き出しは閉じる。病気と看病成功回数は維持し、次のおねだり時刻に通常要求より優先してランダムな看病要求を表示する。ハズレでは怒るReactionを再生する。病気中の「あとでね」は進化・卵用のお世話回数として加算しない。

病気中でも下部の「お世話」から通常の食事・遊び・休憩を利用できる。通常のお世話を開いた場合、表示中の看病要求だけをペナルティなしで保留し、次のおねだり時刻に看病を再開する。

## 表現

- 賢者っちはAnimationと移動速度を低下させ、Emissiveを弱める。
- ワールドっち系は浮遊・移動・発光を弱める。
- ステータスカードへ「看病中」を表示する。
